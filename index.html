About this converter

This page uses a character mapping, not a Pali dictionary or spell-checker. It preserves spaces and punctuation. If several Roman spellings map to the same Shan spelling, reverse conversion uses the first mapping registered, so reverse conversion may not always recover the exact original spelling.

Some entries in the supplied mapping were inconsistent or missing. Review the mapping rules in this file if you need a particular traditional spelling.

Works locally in your browser. No account or server required.
